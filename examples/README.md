| ------------------------------------ | --------------------------------------- |

## Como usar

1. Escolha um exemplo implementado
2. Leia o README do exemplo
3. Entre na pasta do exemplo e execute com `scala run .`
4. Modifique, teste e experimente variações

Cada exemplo é um projeto Scala CLI independente: a versão do Scala e as dependências ficam nas diretivas `//> using` do próprio código.
