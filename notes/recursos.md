## Dicas de Uso

1. **Comece pelo Scala 3 Book** - é gratuito, atualizado e feito para quem está começando
2. **Use o Scala CLI para estudar** - sem arquivo de build, você foca na linguagem
3. **Domine coleções e pattern matching antes das bibliotecas funcionais** - Cats e ZIO ficam muito mais fáceis depois
4. **Escreva testes com MUnit desde o primeiro dia** - `scala test .` já funciona sem configuração
5. **Construa projetos** - CLIs e processamento de arquivos são ótimos primeiros projetos
